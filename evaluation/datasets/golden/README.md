# Golden Baseline Inicial

Este diretorio guarda o baseline manual inicial do benchmark OCR.

Escopo desta primeira iteracao:

- 2 laudos reais anotados manualmente;
- 1 decisao formal de manter `EmissaoDeLaudo.pdf` em shadow set;
- apenas biomarcadores que puderam ser lidos com seguranca do PDF bruto foram promovidos.

Regra:

- o golden nao pode ser enriquecido com saida do OCR como verdade;
- qualquer novo documento precisa de revisao manual campo a campo;
- documentos derivados continuam fora do golden laboratorial.
